# TAV-RAG: Tavily Search API for RAG Enhancement
## Thesis Project: Using Tavily API to Improve RAG Performance

---

## 📋 Project Overview

**Objective:** Develop and evaluate a system that integrates Tavily Search API with Retrieval-Augmented Generation (RAG) to enhance LLM performance through real-time, high-quality information retrieval.

## Setup

1. Create and activate virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the project:
   ```bash
   python main.py
   ```
